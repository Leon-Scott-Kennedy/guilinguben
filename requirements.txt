9=======*args和**kwargs
    *args：接收多个位置参数，对应java中的可变参数，比如

    def func(**kwargs):

10=======python可以像c语言一样传递函数指针，注意：不是直接调用该函数，比如
    def add(left, right):
        return left + right

    def subtract(left, right):
        return left - right

    def operate(func, left, right):
        return func(left, right)

    result1 = operate(add, 5, 3)       # 调用add函数
    result2 = operate(subtract, 5, 3)  # 调用subtract函数

java中也有类似的，但是叫做“方法引用”，比如
    public class MathOperations {
        public static int add(int left, int right) {
            return left + right;
        }

        public static int subtract(int left, int right) {
            return left - right;
        }
    }

    public class Main {
        public static void main(String[] args) {
            BiFunction<Integer, Integer, Integer> addFunction = MathOperations::add;
            BiFunction<Integer, Integer, Integer> subtractFunction = MathOperations::subtract;

            int result1 = operate(addFunction, 5, 3);       // 调用add函数
            int result2 = operate(subtractFunction, 5, 3);  // 调用subtract函数
        }

        public static int operate(BiFunction<Integer, Integer, Integer> func, int left, int right) {
            return func.apply(left, right);
        }
    }

21=======类变量 vs 实例变量
    class Counter:
        count = 0

        def __init__(self):
            Counter.count += 1
    在python中，类变量是属于类的属性，而实例变量是属于对象的属性。类变量在所有实例之间共享，而实例变量是每个实例独有的。
    对应于java的静态变量，比如
    public class Counter {
        private static int count = 0;

        public Counter() {
            count++;
        }

        public static int getCount() {
            return count;
        }
    }

    python中的实例变量，时不需要像java的成员变量一样，写在类的开头，而是可以在构造函数中动态创建。比如
    class User:
        def __init__(self, name, age):
            self.name = name  # 实例变量
            self.age = age    # 实例变量

23=======抽象类与接口

26=======Python 的对象模型与 Java 不完全相同
    Python 中的对象模型是动态的，类和对象都是在运行时创建的。Python 中的类是对象，可以在运行时修改类的属性和方法。而 Java 中的类是静态的，在编译时就确定了类的结构，不能在运行时修改类的属性和方法。
    比如：
    class Dog:
        pass

    dog = Dog()
    dog.name = "小白"（这个对象在运行期还可以动态加属性。）
    Python 中的继承是多继承的，一个类可以继承多个父类。而 Java 中的继承是单继承的，一个类只能继承一个父类，但可以实现多个接口。

    （不理解）Python 中的方法解析顺序（MRO）是基于 C3 线性化算法，而 Java 中的方法解析顺序是基于单继承树。

33=======python的异步编程
    Python 的异步编程主要通过 asyncio 库实现，使用 async/await 语法来定义和调用异步函数。异步编程允许在等待 I/O 操作完成时执行其他任务，从而提高程序的并发性能。
    单线程事件循环驱动的异步模型
    示例：
    ```python
    import asyncio

    async def fetch_data():
        print("Fetching data...")
        await asyncio.sleep(2)  # 模拟 I/O 操作
        print("Data fetched!")
        return {"data": "sample"}

    async def main():
        result = await fetch_data()
        print(result)

    asyncio.run(main())
    ```

    Java 的异步编程主要通过 CompletableFuture 和 ExecutorService 实现，使用回调函数或 Future 对象来处理异步任务。

    示例：
    ```java
    import java.util.concurrent.CompletableFuture;

    public class AsyncExample {
        public static void main(String[] args) {
            CompletableFuture<Void> future = CompletableFuture.runAsync(() -> {
                System.out.println("Fetching data...");
                try {
                    Thread.sleep(2000); // 模拟 I/O 操作
                } catch (InterruptedException e) {
                    e.printStackTrace();
                }
                System.out.println("Data fetched!");
            });

            future.join(); // 等待异步任务完成
        }
    }
    ```

35=======Python 的高并发
    Python 的高并发主要通过多线程、多进程和异步编程实现。由于 GIL（全局解释器锁）的存在，多线程在 CPU 密集型任务中可能无法充分利用多核 CPU，但在 I/O 密集型任务中仍然有效。多进程可以绕过 GIL，充分利用多核 CPU，但开销较大。异步编程适用于 I/O 密集型任务，可以在单线程中处理大量并发请求。
    from concurrent.futures import ThreadPoolExecutor
    Java 的高并发主要通过多线程和线程池实现，Java 提供了丰富的并发工具类，如 ExecutorService、ConcurrentHashMap 等，可以方便地实现高并发应用。
    而java是JUC（Java Util Concurrent）包，python是concurrent.futures包。
